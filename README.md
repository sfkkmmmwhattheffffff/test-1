# Слово — English OGE practice

Public runtime files for the educational platform, published with GitHub Pages.

The `site` directory contains only the HTML, CSS, JavaScript, public curriculum and favicon needed by the website. Raw Quizlet exports, source worksheets, private teaching folders, developer tools and browser profiles are not included.

Student progress, profile details and preferences stay in each visitor’s browser. They are not uploaded to this repository. Public curriculum is included because it is displayed by the website.

GitHub Actions publishes `site` when the `main` branch changes.
